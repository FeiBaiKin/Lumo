# 贡献者许可协议（CLA）

向 Lumo 提交贡献前，请阅读并接受本协议。

## 为什么需要它

Lumo 采用 **AGPL-3.0 开源授权 + 商业授权**的双授权模式（见 [COMMERCIAL.md](./COMMERCIAL.md)）。
这个模式要求项目维护者持有对全部代码的再授权权利：如果代码版权分散在各个贡献者手里，
维护者就无权把项目以 AGPL 之外的条款授予任何人，商业授权这条路会直接断掉。

需要说明的是：单纯的 DCO（Developer Certificate of Origin）**不足以**支撑这件事。
DCO 只证明代码来源合法，并不授予再授权的权利。

本协议**不要求你转让版权**。你仍然是你所写代码的版权人，可以把同一份代码用于任何其他用途。
你授予的是一份许可，不是所有权。

## 协议内容

向本项目提交贡献（Pull Request、补丁、或任何形式的代码与文档），即表示你同意以下条款。

### 1. 版权许可

你授予项目维护者 FeiBaiKin 一份**永久的、全球范围的、非独占的、免费的、不可撤销的**许可，
允许其复制、修改、演绎、公开展示、再许可和分发你的贡献及其衍生作品，
**包括以 AGPL-3.0 之外的许可证（含专有的商业许可证）再许可**。

### 2. 专利许可

你授予项目维护者及本项目的所有使用者一份永久的、全球范围的、非独占的、免费的、
不可撤销的专利许可，涵盖你所拥有的、会被你的贡献必然侵害的专利权利要求，
范围限于制造、使用、销售、许诺销售、进口和以其他方式转让本项目。

若你对任何人提起专利诉讼，主张本项目或本项目中的贡献构成直接或间接专利侵权，
则本协议授予你的专利许可自起诉之日起终止。

### 3. 你的声明

你声明并保证：

- 你的贡献是你的原创作品，或你拥有足以授出上述许可的合法权利
- 你的贡献没有侵犯任何第三方的版权、专利、商标或其他权利
- 如果你的雇主对你的作品拥有权利，你已获得雇主的许可，或雇主已放弃对本项目贡献的权利
- 如果贡献中包含并非你原创的内容，你已在贡献中清楚标明其来源与许可证

### 4. 免责

除上述声明外，你的贡献按「现状」提供，不附带任何明示或默示的担保。

## 怎么接受

在你的第一个 Pull Request 描述中加入下面这行：

```
我已阅读并同意 Lumo 的 CLA（docs/CLA.md）。
签署：你的姓名或 GitHub 用户名 <邮箱>
```

一次签署对你之后的所有贡献持续有效。

## 一点说明

这份协议在开源项目里是常见做法（Apache 基金会、Google、以及多数双授权项目都在用），
目的是让项目在商业上能活下去，不是为了从贡献者身上拿走什么。

如果你不认同这些条款，也欢迎你以 Issue 的形式提出问题或建议——那不需要签署任何东西。
