# 行为准则

## 我们的承诺

为了营造一个开放、友好的环境，参与本项目的所有人——贡献者、维护者、提 Issue 的用户——
都承诺让参与过程不因年龄、体型、身心障碍、族裔、性别认同与表达、经验水平、国籍、
外貌、种族、宗教信仰或性取向而受到骚扰。

## 我们希望看到的

- 用友善和包容的措辞讨论问题
- 尊重不同的观点与经验；技术分歧对事不对人
- 坦然接受建设性的批评，也认真给出建设性的批评
- 以项目整体利益为先
- 对其他参与者保持同理心

## 我们不接受的

- 性化的言语或图像，以及任何形式的性骚扰
- 挑衅、侮辱、贬损的言论，人身攻击或政治攻击
- 公开或私下的骚扰
- 未经许可公布他人的私人信息，例如实际住址或电子邮件
- 其他在专业场合中会被合理认定为不当的行为

## 适用范围

本准则适用于项目的所有空间——Issue、Pull Request、讨论区、提交信息与代码注释，
也适用于任何人以项目代表身份在公开场合的言行。

## 维护者的责任

维护者有权也有责任移除、编辑或拒绝不符合本准则的评论、提交、代码与其他贡献，
并在必要时对违反者采取临时或永久的封禁措施。维护者应当公平一致地执行本准则，
并对被举报者的身份信息保密。

## 举报

遇到违反本准则的行为，请通过仓库的 **Security → Report a vulnerability**
私有通道联系维护者——这是本仓库目前唯一的私密渠道，同样可以用于举报行为问题。
所有举报都会被认真对待并保密处理。

## 来源

本准则参考 [Contributor Covenant](https://www.contributor-covenant.org/) 的原则撰写。
